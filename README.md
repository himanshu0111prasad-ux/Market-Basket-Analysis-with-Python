# Market-Basket-Analysis-with-Python
Executed Market Basket Analysis on e-commerce transaction data using Python (Pandas, NumPy, Scikit-Learn) to apply clustering algorithms, uncovering hidden purchasing behaviors and customer segment trends.

Leveraged machine learning insights to optimize personalized product recommendations, design targeted cross-selling strategies, and drive data-backed decision-making for marketing and inventory bundling.
