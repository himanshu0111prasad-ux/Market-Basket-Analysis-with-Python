# 🛒 Market Basket Analysis & Customer Purchasing Behavior

This repository contains an end-to-end data analytics and machine learning project focused on **Market Basket Analysis** and customer segmentation using a Snapdeal dataset. The project uncovers hidden purchasing patterns, association rules, and customer behavioral groupings to drive strategic retail decisions.

---

## 📌 Project Overview
Understanding customer purchasing habits is vital for cross-selling, product placement, and targeted marketing. 

* **Problem Statement:** Analyze transactional data to discover frequent itemsets, association rules, and customer clusters based on purchasing behavior.
* **Domain:** E-Commerce / Retail Analytics
* **Goal:** Extract actionable insights using clustering algorithms and association rule mining to optimize product recommendations.

---

## 📊 Workflow & Methodology

1. **Data Preprocessing & Cleaning:**
   * Handled missing values, cleaned transaction logs, and standardized data types.
   * Transformed raw transactional records into a basket-format suitable for association analysis.

2. **Exploratory Data Analysis (EDA):**
   * Identified top-selling products, peak purchasing times, and category-wise sales distributions.
   * Visualized spending trends and correlations using Matplotlib and Seaborn.

3. **Machine Learning & Behavioral Clustering:**
   * Applied **K-Means Clustering** to segment customers based on purchasing metrics.
   * Evaluated cluster separation and performance using **Silhouette Score** evaluations.
   * Discovered frequent itemsets and association rules (using metrics like Support, Confidence, and Lift).

---

## 🛠️ Tech Stack & Libraries

* **Language:** Python 3.x
* **Data Handling:** Pandas, NumPy
* **Machine Learning & Clustering:** Scikit-Learn (K-Means, Silhouette Analysis)
* **Visualization:** Matplotlib, Seaborn
* **Environment:** Jupyter Notebook
